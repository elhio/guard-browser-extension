Welcome to Guard!

Guard checks the images on the pages you browse and flags the ones that look AI-generated, violent, or explicit — right where you see them, without uploading anything.

Permissions

Guard is a Safari extension, so Safari has to let it read the pages you visit. That access stays on your device — it's what lets Guard check images as they load.

  • Open Settings → Safari → Extensions → Guard
  • Open Settings → Apps → Safari → Extensions → Guard
  • Turn on Allow Extension
  • Under Permissions, set every website to Allow
  • Open Safari → Preferences → Extensions
  • Open Safari → Settings → Extensions
  • Select Guard in the list and turn it on
  • Set its website access to Allow

Settings

The last step opens in a Settings tab in Safari, where you choose what Guard should look for, what it does when it finds something, and whether to link your Elhio account.
