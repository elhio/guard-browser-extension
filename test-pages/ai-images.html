Guard — Testseite für Bild-Scan & C2PA/KI-Erkennung

Diese Seite bettet die Beispielbilder aus assets/test-data/ ein, damit die Extension sie wie auf einer echten Webseite scannen kann. Lade die Extension (npm run dev oder ein per npm run build gebautes Paket), öffne diese Seite, dann die DevTools-Konsole (F12) und schaue nach Zeilen, die mit [Guard] beginnen.
